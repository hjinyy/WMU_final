# File responsibility and data flow

The repository has two isolated one-way reproduction flows:

- Figures: `data/frozen_inputs + data/reference` → `src/wmu_final` → `scripts/render|audit` → `outputs` → tests.
- Step 3 ML: `analysis/fault_generalization_step3_v1/inputs` → its `scripts/` → its `outputs/` → its tests and SHA inventory.

- **Frozen input tables** are not generated by the figure scripts. `data/frozen_inputs/predictions` and `metrics` hold the precomputed rows required by the selected figures; `waveforms_selected` contains six channel-reduced traces for matched SSO comparisons. The Step 3 package separately freezes its integrated manifest, Step 2 C1–C4 feature tables, detector diagnostics, and upstream verification under `analysis/fault_generalization_step3_v1/inputs`; no raw full-corpus waveforms or Simulink models are included.
- **Reusable figure source** is limited to network branch lists and frozen-feature/spatial-normalization helpers. The separate Step 3 package includes a portable ML evaluation/selection implementation and an exact snapshot of the executed source; neither contains a simulation runner.
- **Figure scripts** are executable entry points. `scripts/render` owns plot creation; `scripts/audit` owns the pre-fault persistence audit. Each figure script writes to one explicit child of `outputs` and refuses overwrite unless `--force` is supplied.
- **Step 3 scripts** are confined to `analysis/fault_generalization_step3_v1/scripts/`; the evaluator and train-only CV selector refuse to overwrite existing output paths and accept a new `--output` path for reproductions.
- **Outputs** are deliverables, not inputs to the generators. Image/PDF, caption, numerical plot data, metadata, and diagnostics remain together under each named deliverable.
- **Tests** check role boundaries, expected output inventory, provenance, and frozen-input hashes. The package inventory is SHA-256 based and stored with the provenance files.

Do not put archived prediction tables under `outputs`, and do not put rendered figures under `data`: those locations indicate different provenance and lifecycle.
